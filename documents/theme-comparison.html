Theme System

Light & Dark, Side by Side

Nexus is dark-first but ships a complete parallel light theme — same type, spacing, gold accents, and components, re-skinned through the surface/text/border token tiers. The screen below is rendered from one set of markup, themed entirely by swapping CSS-variable values. Both directions clear WCAG 2.2 AA.

Dark · Default

Task-focused tools

Dealer ops dashboards, inventory, protection-ops, pipelines. Elevation built from surface-color progression (page → card → raised), no shadows.

Light · Parallel

Data-dense, long-session

Reporting and admin tools where users read for extended stretches. Cream page, white cards, elevation built from soft Material-style shadows.
