Theme System · Analytics Direction

Two themes, one set of tokens

The Bish's RV Analytics palette, type, and components — re-skinned across the surface / text / border token tiers. This is the alternate direction to Nexus: cooler, light-first, humanist sans, teal accents. The dashboard below is rendered from one set of markup, themed entirely by flipping the data-theme attribute. Both directions clear WCAG 2.2 AA.

Light · Default

Everyday reporting

Data-dense recipe and ops reports for daily use. Cool-gray page, white cards, soft Material-style shadows for elevation, teal accents.

Dark · Parallel

Long-session, focused

Task-focused dashboards for extended stretches. Charcoal surfaces with elevation built from surface-color steps; titles brighten to cyan-teal.
