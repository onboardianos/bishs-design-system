# Portal · Dark UI Kit

Dark-theme recreation of the Bish's RV internal portal (Nexus v1.0). The signature look: black page, dark-green cards, gold accents, cream body text, stencil display titles.

## Components
- `Header.jsx` — branded page header with gradient, gold border, eyebrow/title/meta
- `TabBar.jsx` — sticky underline tabs
- `Button.jsx` — 4 variants × 3 sizes, M3 state layers
- `Badge.jsx` — 6 semantic pill types
- `Input.jsx` — labeled input with helper + error states
- `Card.jsx` — header/body/footer three-part card
- `StatTile.jsx` — KPI tile with label, value, delta
- `UnitRow.jsx` — inventory list row (ID, meta, status badge, action)

## Demo
