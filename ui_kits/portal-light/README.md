# Portal · Light UI Kit

Light-theme parallel of the dark portal kit. Same Nexus token contracts — same gold, same Bebas Neue, same 4px spacing — re-skinned for data-dense admin surfaces, reporting, and marketing-adjacent tools. Elevation comes from **shadow** here (not color progression like the dark theme).

## Demo
`index.html` → the same interactive click-through pattern as `portal-dark/`, on a cream page with white cards, darker semantic colors for AA contrast on light.

## Key differences from dark
- Page: `#F7F6F1` (warm cream), Cards: `#FFFFFF`
- Text: `#0A0A09` primary, `#3D3D38` body (replaces cream)
- Semantic colors shift to their `-dark` variants for AA contrast (success `#1B7A2E`, warning `#C77C00`, danger `#B02525`, info `#1864AB`)
- Cards use Material-style shadow stack instead of raised-surface color
- Gold borders deepen slightly (`rgba(139,117,46,0.45)`) for visibility on cream
