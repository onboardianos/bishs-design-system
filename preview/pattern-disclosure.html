Pattern · Progressive Disclosure
Four containers, four roles. Choose by user intent — not by convenience.
Tabs
Peer Categories
Switch between equal-weight views of the same dataset. All options always visible; state persists per user.
Use when: 2–5 peer filters
Accordion
Optional Detail
Secondary info most users skip. Collapsed by default; one or many open at once.
Use when: detail is opt-in
Drawer
Inspect & Return
Peek at a record without losing list context. Three ways out: Esc, backdrop, X. Action-first for ICs.
Use when: user will inspect >1
Modal
Interrupt Worthy
Confirmation, destructive action, required form. Narrow only. If it scrolls, it's a page.
Use when: can't proceed without
