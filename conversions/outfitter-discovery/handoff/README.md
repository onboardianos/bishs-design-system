## How to run
Open `../index.html`. **Prototype** mode walks the 20 states from the side panel; **Canvas** shows every state at 1280, plus key states at 834 and 390. Review at 1440 → 375 with the shrink test, then 200% text zoom.

## Production stack
Tailwind v4 CSS-first, tw-animate-css, shadcn v4 new-york on Radix, Lucide. The decision engine (`data/engine.js`) is plain JS with a Node export, so it can run server-side behind the s18 endpoints unchanged.
